# 搬瓦工 VPS 入门：从用途判断到首次 SSH 登录

第一次接触 VPS，难点往往不是看到服务器配置，而是弄清楚它适合做什么、应该如何管理。搬瓦工 VPS 需要通过控制面板和命令行操作；购买后，你要先从 KiwiVM 找到连接信息，再使用 SSH 登录。本文按实际使用顺序说明用途判断、套餐比较、初次连接和基础管理，适合正在了解 VPS 或刚拿到服务器的新手。

## 搬瓦工 VPS 是什么，适合谁使用

VPS 是一台由服务商提供、可通过网络远程管理的虚拟服务器。搬瓦工提供的服务以 Linux 服务器使用为主，管理入口包括 KiwiVM 控制面板和 SSH 命令行。它不是开机后就能直接使用的图形桌面电脑：系统中的软件安装、配置和维护通常需要你登录服务器后操作。

如果你希望练习 Linux，可以把 VPS 用于熟悉终端、文件与系统管理；如果你已经了解基础命令，也可以将它作为部署个人网站等服务的服务器。两类用途都需要先理解服务器状态、登录凭据和系统环境。刚开始时，建议先完成登录并熟悉面板，再进行系统重装或安装服务，避免还未掌握恢复方式就改动重要设置。

VPS 是否适合你，取决于是否愿意自行管理系统。选择套餐之前，先写下具体用途：是练习命令行，还是准备部署网站；预计需要多少资源；对机房或线路类别是否有明确偏好；预算能够接受怎样的付款周期。没有一种配置适用于所有人，价格、资源和产品类型都应结合实际用途比较。

## 首次登录：KiwiVM 控制面板与 SSH

购买并开通服务后，先登录账户，进入 **Services → My Services**，找到对应 VPS，再打开 **KiwiVM Control Panel**。KiwiVM 是管理 VPS 的控制面板；这里的操作对象是服务器本身，不是你电脑上的本地系统。

在面板首页找到连接所需的信息：

- **Public IP address**：服务器的公网 IP，SSH 命令中的服务器地址。
- **SSH Port**：SSH 服务使用的端口。不要默认认为它一定是 22，应以面板显示为准。
- **root 密码**：在左侧选择 **Root password modification**，再点击 **Generate and set new root password** 可重设密码。重设时 VPS 需要处于开机状态，新密码会发送到注册邮箱。

请逐项确认 IP、端口与密码，避免把其他服务器的信息混在一起。Windows 可以打开 PowerShell；macOS 或 Linux 用户可以打开系统终端，输入以下命令，将示例文字替换成面板中的实际值：

```bash
ssh root@服务器IP -p SSH端口
```

例如，`root` 表示以 root 用户登录，`服务器IP` 应替换为公网 IP，`-p` 后面填写面板显示的 SSH 端口。首次连接时，终端可能询问是否信任该主机；确认连接对象无误后再继续。随后根据提示输入密码。终端输入密码时通常不会显示字符，这是命令行的常见交互方式。若无法登录，先不要连续重设密码或改动系统，按下文顺序核对连接信息和服务状态。

连接成功后，你就进入远程 Linux 系统。建议先确认自己操作的是哪台服务器，并谨慎使用需要管理员权限的命令。密码和私钥都是登录凭据：不要将其公开粘贴到论坛或聊天中，也不要把 SSH 私钥上传到不可信位置。

## 初次使用后的基础管理

KiwiVM 提供一些服务器管理入口。**Main controls** 可用于开机、关机或重启；操作前先确认当前服务器和任务，尤其是在有服务运行时，关机或重启可能中断正在进行的工作。若面板显示服务器状态与预期不符，可先查看状态，再决定下一步，而不要反复点击控制按钮。

如需更换系统，可在 **Install new OS** 中查看可用选项。参考内容列出的系统包括 Ubuntu、Debian 和 CentOS。选择系统时应考虑自己要使用的软件及所参考的教程是否适用；不同系统的命令和配置方式可能不同。重装系统会改变原有系统环境，开始前先确认需要保留的数据，并在操作前安排好备份。不要把重装当成不会影响现有内容的普通更新。

面板中的 **Snapshots**、**Automatic Backups** 和 **SSH Keys** 分别对应快照、自动备份与 SSH 公钥管理。使用前了解当前账户和面板所提供的选项，并确认备份是否包含你需要的数据；不要假定快照或备份已自动开启，也不要在没有核实可恢复内容前删除原数据。SSH 公钥可用于密钥认证；若采用这种方式，应妥善保管与公钥配对的私钥。

部分产品可能提供机房迁移入口。迁移前应核对面板中该服务可选的目标和提示，并预先考虑依赖服务器 IP 的配置，因为迁移可能导致 IP 地址变化。不要把迁移理解为完全无影响的切换，也不要在未确认服务依赖的情况下操作。

## SSH 连不上时，按顺序排查

遇到连接失败，可以依次检查以下事项：

1. **核对连接命令。** 确认 IP 和 SSH 端口来自当前 VPS 的 KiwiVM 页面，命令中的 `-p` 后填写的是端口而不是 IP；用户名应与账户设置相符。
2. **核对凭据。** 若密码不确定，回到控制面板查看可用的重设流程，并确认账户邮箱能接收相关信息。不要把密码发送给他人代为“测试”。
3. **检查服务器状态。** 在面板查看 VPS 是否处于开机状态；刚进行控制操作或重装后，先依据面板状态确认操作结果。
4. **查看面板提供的检查项。** 若 KiwiVM 中提供 **Check if my IP is banned** 工具，可按页面说明检查；不同账户界面或可用选项应以实际显示为准。
5. **再寻求账户支持信息。** 若连接信息正确、服务状态正常而问题仍存在，记录错误提示并查看账户面板提供的帮助或支持渠道。描述问题时避免附上密码、私钥等敏感凭据。

能够登录后，也应做好基本的凭据管理：选择不易泄露的密码，限制密码和密钥的访问范围；如果使用 SSH 密钥，备份私钥并保护其文件。确认操作对象、数据是否需要保留以及面板提示，是执行重装、迁移等变更前的必要步骤。

## 一个稳妥的开始顺序

先确定服务器用途和预算，再比较产品类型、机房选择与资源规格；通过对应产品入口核对购买页面信息。开通后进入 KiwiVM，记录 IP 和 SSH 端口，按面板流程获取凭据并完成首次登录。熟悉服务器状态和基础管理后，再考虑安装软件或调整系统。这样逐步开始，既能把选择依据说清楚，也能降低因信息混淆或贸然变更造成的问题。
