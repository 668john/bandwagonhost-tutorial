# 搬瓦工 VPS 使用指南：选套餐、连接服务器与开始部署

购买 VPS 之前，先想清楚要在服务器上做什么，比先选一个套餐名称更重要。本文从 Linux 学习、个人网站和应用部署等需求出发，介绍搬瓦工的产品规格、KiwiVM 控制面板与 SSH 的基本用法，以及重装、备份和迁移时需要考虑的事项。

## 从用途判断 VPS 是否适合自己

搬瓦工（BandwagonHost）提供 VPS 服务。VPS 是通过虚拟化技术提供的远程服务器：你可以安装系统和软件，但也需要自己管理配置、账号和数据。它不像一台已经装好所有应用的个人电脑，买完之后通常还要连接服务器、安装所需程序并维护运行环境。

使用时有两个不同的入口。**KiwiVM** 是管理服务器的控制面板，可查看连接信息和进行开关机等操作；**SSH** 则是从自己的电脑远程登录系统的方式，登录后可以在命令行中操作 Linux。面板和系统各自承担不同职责：知道如何进入面板，才能在 SSH 出现问题时多一个检查入口。

如果目的是学习 Linux，可以先练习查看系统状态、管理文件和理解软件包；如果准备做个人网站，则还要考虑域名、Web 服务、数据库和备份；部署应用时，需要先核对项目对系统、内存和磁盘的要求。新手也可以从 VPS 开始，但应愿意学习命令行，并为更新、凭据保护和故障排查留出时间。已有重要数据时，不要把一台服务器当成唯一的保存位置。

## 首次连接：从控制面板到 SSH

服务开通后，在账户后台依次进入 **Services → My Services**，找到要使用的 VPS，点击 **KiwiVM Control Panel**。如果账户内有多台服务器，先确认当前页面对应的是哪一台，后续的密码重设和系统操作也要针对同一服务。

面板首页的 **Public IP address** 是连接地址，**SSH Port** 是登录端口。端口应照面板填写，不要假定它一定是 22。需要重设 root 密码时，在左侧选择 **Root password modification**，点击 **Generate and set new root password**；重设时 VPS 需要处于开机状态，新密码发送到注册邮箱。先确认自己可以访问该邮箱，并妥善保管收到的凭据。

Windows 可使用 PowerShell，macOS 和 Linux 可打开终端。输入下面的命令，把地址和端口替换为面板显示的值：

```bash
ssh root@服务器IP -p SSH端口
```

其中 `ssh` 是连接程序，`root` 是登录用户，`@` 后面填写服务器公网 IP，`-p` 指定端口。首次连接时可能出现主机身份确认提示，应先核对目标主机的指纹，再决定是否接受。输入密码时终端通常不会显示字符；输入完成后按回车即可，不必因为屏幕没有变化而重复输入。

登录后，命令操作的是远程服务器，而不是自己的电脑。root 拥有较高权限，执行删除、重装和安装命令前应确认对象及影响。不要把密码或私钥贴到公开页面；也不要把不理解的命令直接复制到管理员终端执行。

## 学习 Linux 与管理服务器

刚连接时，可以先用查询命令了解系统。以下命令以查看信息为主，不负责安装或更新软件：

```bash
uname -a        # 查看内核等系统信息
lsb_release -a  # 查看发行版信息（如果系统提供此命令）
df -h           # 查看文件系统空间使用情况
free -h         # 查看内存使用情况
top             # 查看运行中的进程；按 q 退出
```

查看磁盘时，留意系统分区的已用和可用空间；查看内存和进程时，可以先观察应用启动前后的变化。命令输出只是某一时刻的状态，不能单凭一次结果断定系统长期负载。`lsb_release` 也可能因系统环境不同而不可用。

与这些查询不同，`apt update` 和 `apt upgrade` 会涉及软件包列表或已安装软件的更新，适用于使用 APT 的系统。更新前应了解拟进行的变更、检查重要服务，并准备恢复数据的方法；不要把带有自动确认选项的升级命令当作无影响的状态查询。

KiwiVM 的 **Main controls** 用于开机、关机和重启；如果网站正在运行，这些操作可能中断访问。**Install new OS** 提供系统重装入口，可在面板查看 Ubuntu、Debian 等可用系统。重装前先保存需要的文件、数据库和配置，确认备份可用，并核对面板提示；重装会改变原有系统环境，不应作为普通更新使用。

面板还列有 **Snapshots**、**Automatic Backups** 和 **SSH Keys**。快照可用于记录服务器状态，自动备份可按面板提供的方式配置；两者的可用选项与恢复范围应在实际操作时确认。除了检查是否成功创建备份，还要考虑怎样恢复网站文件和数据库，避免在未确认恢复内容前删除原数据。SSH Keys 用于管理公钥；使用密钥登录时，配对的私钥应留在受保护的位置，不能公开分享。

需要更换机房时，可查看面板中的 **Migration** 入口及该服务实际提供的目标。迁移可能涉及 IP 变化，因此事先记录域名解析、应用配置中使用的地址，并准备备份；完成后再核对连接和服务状态。不要在不了解面板提示及数据影响时直接迁移。

## 从服务器到网站或应用

### 个人网站与 WordPress

建站不只是安装一个程序。先确认所选系统及登录方式，然后准备 Web 服务器、数据库和 PHP 等运行环境；参考方案使用宝塔面板管理 LNMP 环境，再创建站点和数据库，上传 WordPress 安装包或使用面板提供的安装方式。安装时应记录数据库名称和凭据，并将它们与面板管理员账号分开管理。

如果使用域名，还需要将域名解析指向服务器，并按站点需要配置证书。部署完成后，检查网站能否访问、管理入口是否受到保护，以及文件和数据库怎样备份。安装远程脚本前，应查看来源和内容并核对软件的当前安装说明，不要未经审查就以 root 身份执行下载的脚本。

### Dify 等应用

Dify 的 Docker 部署路径是先准备 Docker 和 Docker Compose，再获取 Dify 项目，在其 `docker` 目录中配置环境文件并启动服务。可先查阅 [Dify 项目仓库](https://github.com/langgenius/dify.git)，核对当前安装步骤、资源需求和版本要求；不要假定某个 VPS 配置一定能满足实际工作负载。

服务启动后，还需要在应用设置中选择模型提供商并配置 API Key。密钥应像服务器密码一样保管，不要提交到公开仓库或粘贴在求助信息中。使用外部模型服务时，也应了解数据如何发送给相应提供商；把应用部署在自己的服务器上，并不自动意味着所有数据都只留在本机。

## 连接失败时先检查什么

搬瓦工远程连接失败时，先保留错误提示，再依次排查：

1. 确认 SSH 命令中的 IP、端口和用户名属于当前 VPS，端口填写在 `-p` 后。
2. 在 KiwiVM 的 Main controls 查看服务器是否开机；如果刚执行过重装或重启，先确认操作状态。
3. 核对密码或密钥是否与当前登录方式匹配。需要重设密码时，确认服务器状态及注册邮箱，再按面板流程操作。
4. 若面板提供 **Check if my IP is banned**，可按页面说明使用。检查结果只是排查线索，不能代替对端口、凭据和服务状态的核对。
5. 仍无法解决时，记录具体错误并通过账户提供的支持渠道咨询；提交信息时删除密码、私钥和其他敏感内容。

选择、连接和部署可以分阶段进行：先核对用途、预算和产品页面，再完成首次登录；在熟悉备份和恢复方式后，才对系统或应用做较大变更。这样遇到问题时，也更容易判断是连接信息、服务器状态还是应用配置需要检查。
