# 搬瓦工 VPS 入门：从首次连接到选择方案

这份指南面向刚接触 VPS 的用户，介绍搬瓦工服务器的基本用途、如何通过 KiwiVM 获取 SSH 连接信息，以及开始前可比较的几种方案。VPS 适合练习 Linux、搭建个人网站或运行自己的应用；实际选择取决于用途和所需资源。

## 首次连接服务器

购买后，从账户的 **Services → My Services** 找到对应服务，进入 **KiwiVM Control Panel**。在面板中查看服务器的公网 IP 和 SSH 端口，并按账户页面的指引获取或设置 root 密码。连接时需要这几项信息。

在 Windows PowerShell、macOS 或 Linux 终端中运行以下命令，将示例文字替换为面板显示的实际信息：

```bash
ssh root@你的服务器IP -p 你的SSH端口
```

请勿分享密码或私钥。首次登录后，建议了解 SSH 密钥登录和系统更新等基础管理方式。

## Linux 学习与系统管理

远程 VPS 可以作为练习 Linux 命令行的环境。KiwiVM 面板提供 **Install new OS** 等管理入口，可用于重装系统；重装前应先确认重要数据已备份，因为该操作可能影响服务器上的数据。可选系统及具体操作以当前面板显示为准。

KiwiVM 还列有开关机、快照、自动备份、SSH Keys 等管理功能。不同功能的可用范围和数据恢复方式应以面板说明为准；快照或面板备份不应替代独立保存的重要数据副本。

## 个人建站

常见的入门方向是先准备 Linux 环境，再部署网站运行环境和内容管理程序，例如 WordPress。使用宝塔面板等管理工具也是一种选择。部署前确认应用所需的系统与资源，并为网站文件和数据库安排备份。

## 开始前的检查

- 保存 KiwiVM 登录入口及服务器连接信息，并妥善保管凭据。
- SSH 无法连接时，先核对实例状态、IP、端口和登录信息。
- 重装系统、迁移机房或进行其他可能影响数据的操作前，先备份并阅读当前面板说明。
- 按自己的用途选择资源；不确定时，先核对方案详情和相关条款，再决定付款周期。
